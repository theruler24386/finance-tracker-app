# Finance Tracker App

A simple personal finance tracker web app built with HTML, CSS, and JavaScript. It lets users log income and expenses, view totals, and track category budgets.

## Features

- Add income and expense entries
- Track spending by category
- See total income, expenses, and remaining balance
- View budget progress for major categories
- Delete transactions
- Data is saved in the browser using localStorage

## Run locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app:
   ```bash
   npm start
   ```

3. Open your browser to:
   ```text
   http://localhost:3000
   ```

## Project structure

- `server.js` - Express server
- `public/index.html` - Main interface
- `public/styles.css` - App styling
- `public/app.js` - App logic and localStorage handling

## Notes

This is a lightweight MVP suitable for personal use. If you want, it can later be extended with authentication, a database, charts, or recurring transactions.
